技术转移的知识产权模块

技术转移的核心标的往往是知识产权（特别是专利）。没有知识产权保护的技术，很难在市场上交易——因为谁都可以免费复制。这节课帮你掌握技术经理人必须了解的IP基础知识。

类型创新要求审查方式含金量

注意：在技术转移中，发明专利的价值通常远高于实用新型和外观设计。投资人和合作方更看重发明专利，因为它经过了实质审查，权利稳定性更高。

职务发明：权属是关键

职务发明：执行本单位任务或主要利用本单位物质条件完成的发明创造。

法律规则：

  • 专利申请权 → 属于单位（不是个人）
  • 发明人享有 → 署名权 + 获得奖励权
  • 单位转让/许可后 → 须向发明人支付不低于50%的奖酬

这在技术转移中极其重要：技术经理人需要确认技术的权属是否清晰。如果发明人离职了、单位变更了、或者有多个合作单位，权属纠纷会直接导致交易失败。

专利布局策略

一项有价值的成果，不应只申请一件专利，而应围绕核心技术构建专利组合：

常见布局策略

  • 星形布局：一件核心专利 + 多件外围改进专利
  • 伞形布局：一项基础专利覆盖上位概念，多件从属专利覆盖下位应用
  • 网络型布局：多维度交叉申请，形成密集保护网

技术经理人评估技术时，要看的不只是"有没有专利"，而是"专利布局是否完善"——单件专利很容易被规避，专利组合才有真正的壁垒。

FTO分析：商业化的"安全带"

FTO (Freedom to Operate)，自由实施分析。在技术商业化之前，必须评估：我们的产品/技术会不会侵犯别人的专利？

  1. 检索相关技术领域的有效专利
  2. 分析权利要求范围
  3. 判断自己的技术方案是否落入保护范围
  4. 如有风险，设计规避方案或准备许可谈判

真实风险：很多企业投入大量资金研发新产品，上市后才发现侵犯了他人专利，面临巨额赔偿和禁令。FTO分析是避免这种灾难的关键前置动作。

知识产权侵权防范

实务中，知识产权侵权防范通常包含以下要点：

  • 研发前：做专利检索（查新），避免重复研发和侵权
  • 研发中：做好技术秘密管理，签署保密协议
  • 申请时：找专业代理机构撰写专利申请文件
  • 转化时：做FTO分析，确认权利稳定性和侵权风险
  • 合同中：明确知识产权归属、许可范围、侵权责任
