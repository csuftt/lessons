Go 术语速查(Java 架构师版)

读 tdengine-replicator 时反复出现的术语,左侧 Go、右侧 Java 对应

这份速查表收录读 Go 项目最高频的术语。每条都给 Java 对应物与关键差异。课程中遇到陌生词,先来这里查。

项目与模块

Go · go.modmodule 声明 + 依赖清单(require)。module github.com/suiteng/tdengine-replicator 是模块全局唯一路径。
Java · pom.xmlMaven 坐标 + dependencies。Go 依赖版本精确锁在 go.sum。
Go · package同目录所有 .go 文件必须同 package。包名 = 导入名。
Java · packageGo 更严格:一个目录一个包。
Go · package main可执行程序的包。func main() 是入口,无参数无返回。
Java · main 方法public static void main(String[] args)。Go 的 main 不接命令行参数(用 os.Args 取)。
Go · 首字母大小写=可见性大写开头=导出(包外可见,如 Config);小写=包内私有(如 loadConfig)。无 public/private 关键字。
Java · public/privateGo 用首字母大小写替代修饰符。

语法核心

Go · :=短变量声明+推断类型,只能在函数内。cfg := loadConfig()
Java · varvar cfg = loadConfig();(Java 10+)。
Go · 多返回值函数可返回多个值。b, err := os.ReadFile(p)
Java · 异常Java 抛异常;Go 把 error 当普通返回值。
Go · error内置接口(Error() string),不是异常。if err != nil 最高频惯用法。
Java · ExceptionGo 没有 try/catch,错误逐层返回。
Go · nil指针/接口/slice/map/channel 的零值,表示「空」。
Java · null类似,但 Go 的 nil 是有类型的。
Go · struct字段集合,值类型。无继承,靠组合。
Java · classGo 没有类,struct + 方法 + interface 替代。
Go · 接收者(值/指针)func (t T) m() t 是副本;func (t *T) m() t 是指针。修改状态必须用指针接收者。
Java · thisJava 对象天然引用,无副本概念。
Go · defer函数返回前执行(栈式,后进先出)。常用于关连接。
Java · try-finally等价 finally。

容器

Go · slice []T动态数组。append(s,x) 须赋值回。切片 s[:n] 共享底层数组(评审重点)。
Java · ArrayListsubList 也共享,但 Go 覆盖所有切片操作。
Go · map map[K]V哈希表。v, ok := m[k] 判存在。nil map 写入 panic(须 make)。
Java · HashMapput/get。

接口与类型

Go · 隐式实现类型无需 implements,方法集匹配即满足。「消费方定义接口」。经验:1~3 方法最佳。
Java · 显式 implements必须声明。Go 鸭子类型是最大转变。
Go · any / interface{}零方法接口,任何值都能装。Go 版 Object。
Java · Object编译期不知类型,运行期才知。
Go · 类型断言v := x.(T)(失败 panic)vs v, ok := x.(T)(安全)。优先双值。
Java · instanceof + 强转x instanceof T t(Java 16+)。
Go · type switchswitch v := x.(type){case T1:...},每 case 内 v 是该具体类型。
Java · instanceof 链理念接近。

并发

Go · goroutinego f() 启轻量线程(M:N,几 KB 栈)。无返回值。评审重点:能否通过 ctx 退出(防泄漏)。
Java · 虚拟线程Java 21 Thread.startVirtualThread。
Go · channelchan T,goroutine 间管道。发/收都阻塞。close(ch) 后接收不再阻塞。chan struct{} 当纯信号。close 责任必须唯一。
Java · BlockingQueue/Latchchannel 更万能:可当队列、锁、信号。
Go · selectchannel 版 switch(和普通 switch 不同)。多路复用「哪个 channel 先就绪」。带 default=非阻塞,不带=阻塞。
Java · Selector/NIO理念类似多路复用。
Go · context.Context取消/超时/传值载体。几乎所有长函数第一个参数。<-ctx.Done() 收取消。WithCancel/WithTimeout 必须 defer cancel()。树状:取消父→所有子取消。
Java · 无直接对应接近「取消信号 + scoped 值」。
Go · sync.WaitGroupAdd(1)/Done()/Wait(),等一群 goroutine 结束。Add 与 defer Done 必须配对。
Java · CountDownLatch最接近。
Go · sync.MutexLock()/Unlock() 显式成对,无 synchronized。每条 return 都要 Unlock。
Java · synchronized/ReentrantLockGo 更原始显式。
Go · sync.OnceOnce.Do(f) 保证 f 只执行一次,并发安全。常用于初始化/告警去重。
Java · 双检锁单例Once 一行替代。

项目导航

Go · 同 package 共享同目录同 package 的 .go 文件,符号无需 import 直接可见。这是没 import 却能调用的原因。
Java · 同类内方法类比为同 class 不同段落。
Go · //go:embed编译时把文件嵌入二进制。//go:embed init.sql + var initSQL string。运行时不依赖外部文件。
Java · classpath 资源用 ClassLoader 读 resources。
