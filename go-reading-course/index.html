读懂并评审 Go 项目

以 tdengine-replicator 为实战 · 面向 Java/Spring 架构师

这是一套为 Java 架构师设计的 Go 阅读课。每课 8–15 分钟,锚定你项目里的真实代码,用 Java→Go 映射作脚手架。建议按顺序读,每课末尾的折叠自测真做一遍。底部「下一课」可直接跳转。

课程

  1. 从 main.go 入手:程序入口与启动流程 入门package / func / := / go。读懂启动顺序 = 理解程序骨架。
  2. 错误处理与 defer:Go 没有 try/catch 核心error 返回值 / if err != nil / defer / 多返回值。评审第二大重点。
  3. struct、方法与指针接收者 核心没有 class 的面向对象。值接收者 vs 指针接收者(评审高发 bug)。
  4. slice、map 与 nil:容器与共享陷阱 核心append 要赋值 / 切片共享底层数组 / nil map 写入 panic。
  5. interface:Go 的鸭子类型 设计隐式实现 / any / 类型断言 / type switch。Java 架构师的关键一跃。
  6. goroutine、channel 与 select 并发并发原语三件套。goroutine 泄漏 = 评审第一大雷区。
  7. context 与 sync:并发协调 并发ctx 取消树 / WaitGroup / Mutex / Once。把 goroutine 组织起来。
  8. 项目导航与数据流 综合go.mod / 同 package 共享 / go:embed / 14 文件分工图 / 主数据流 / 通用读法清单。
  9. Go 代码评审清单(capstone) 实战A→B→C→D→E 五维清单,逐条套用到 tdengine-replicator,产出真实 review。
