zcode.cjs 协议课：app-server API 全操作

目标：从零把一个 GUI 宿主接到 zcode.cjs app-server 上—— 拉起进程、订阅事件流、切换模型、处理审批与提问，全操作走一遍。内容以真实 IDE 插件项目的线上实现为蓝本，所有结论都经真实帧验证。

它是什么

🔌 对接对象

  • zcode.cjs 的 app-server 子命令
  • stdio 上的行式 JSON-RPC（方言：无 jsonrpc 字段）
  • 会话 / 模型 / 工具 / MCP / 定时任务全在后端

📡 通信形态

  • 宿主 → CLI：约 30 个请求方法
  • CLI → 宿主：事件通知流 + 7 类反向请求
  • v4 面：订阅、行模型、写命令（CAS 并发）
