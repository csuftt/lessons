五、易错点（本仓库踩过的）

  • VirtualFile.isFile 不存在——Kotlin 里没有 Java 那种属性名错觉，查 SDK 要用 isDirectory 反转或用 file.isValid。
  • 与 Java 互操作时 put 有重载歧义（Java 方法 put(K,V) 与 Kotlin 集合扩展冲突），需显式类型参数。
  • Boolean? 不能直接当 if 条件，必须 == true 或 ?: false。
  • !! 是代码味道：能用 ?.let / ?: 就别用。
