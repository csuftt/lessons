技术栈地图

🧩 插件端 · Kotlin

  • Kotlin 1.9.24 / JVM 17 / Gradle

  • Service / ToolWindow / JCEF
  • 协程 + EDT 线程模型

🎨 Webview 端 · TS/React

  • React 19 + TypeScript 5.7 + Vite 7
  • Zustand 状态管理
  • Less 样式 + singlefile 打包
  • JCEF IPC 双向桥（bridge.ts）
